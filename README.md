# A-Maze-İng

| Anahtar | Açıklama | Örnek |
|---|---|---|
| WIDTH | Labirent genişliği (hücre sayısı) | `WIDTH=20` |
| HEIGHT | Labirent yüksekliği | `HEIGHT=15` |
| ENTRY | Giriş koordinatları (x,y) | `ENTRY=0,0` |
| EXIT | Çıkış koordinatları (x,y) | `EXIT=19,14` |
| OUTPUT_FILE | Çıktı dosya adı | `OUTPUT_FILE=maze.txt` |
| PERFECT | Labirent mükemmel mi? | `PERFECT=True` |
